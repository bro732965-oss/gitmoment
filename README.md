# gitmoment

A simple, ad-free social network. Share photos, follow friends, and stay connected.

## Download

**Android APK:**  [![Open gitgot](https://img.shields.io/badge/Open_gitgot-3DDC84?style=for-the-badge&logo=android&logoColor=white)](gitmoment.apk)


**Web version:** [![Open gitgot](https://img.shields.io/badge/web_gitgot-FF6B6B?style=for-the-badge&logo=netlify&logoColor=white)](https://gitmoment.netlify.app)
## Features

- 📸 Share photos
- 👥 Follow people
- 💬 Comment on posts
- 🔍 Find users/posts

## Requirements

- Android 5.0 or higher
- Internet connection

## Installation

1. Download the APK
2. Open the file
3. Allow installation from unknown sources
4. Launch the app
