# gitmoment

A simple, ad-free social network. Share photos, follow friends, and stay connected.

## Download

**Android APK:** [Download](gitmoment/gitmoment_1.apk)

**Web version:** [Open](https://gitmoment.netlify.app/)

## Features

- 📸 Share photos
- 👥 Follow people
- 💬 Comment on posts
- 🔍 Find users/posts

## Requirements

- Android 5.0 or higher
- Internet connection

## Installation

1. Download the APK
2. Open the file
3. Allow installation from unknown sources
4. Launch the app
